# 📝 Atividade Individual - Lista de Tarefas em Angular

Aplicação simples desenvolvida para o bootcamp da **WoMakersCode** com o objetivo de praticar componentes, templates, data binding, eventos e diretivas básicas do Angular.

## 🎯 Requisitos Implementados

- **Visualização de tarefas:** Exibição da lista com tarefas previamente cadastradas.
- **Adicionar tarefa:** Campo de entrada e botão para incluir novas tarefas (com validação contra campos em branco).
- **Concluir tarefa:** Caixa de seleção para marcar tarefa como concluída (com texto riscado).
- **Remover tarefa:** Botão individual para excluir a tarefa da lista.
- **Contador:** Atualização automática da quantidade de tarefas concluídas no rodapé.
